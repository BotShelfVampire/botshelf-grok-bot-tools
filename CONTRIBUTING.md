# Contributing

- One item per pull request. Keep the shape of the existing items: what it does, where it goes, where it stops, first three moves, blanks.
- Every product fact needs an official source listed in `SOURCES.md`. No guessed UI labels or limits.
- Do not write that something was tested unless you add the record: what you ran, on what, and the result, with private data removed.
- Every text stops before sending, publishing, purchasing, paying, deleting or changing production.
- No secrets, no real customer data, no copies of other people's shared Bots.
