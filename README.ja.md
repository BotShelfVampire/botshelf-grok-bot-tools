## 使い方

| 種類 | 貼る場所 |
| --- | --- |
| スキル | **Grok Build：** `skills/<名前>/` をリポジトリの `.grok/skills/`（または `~/.grok/skills/`）に写します。`/<名前>` で呼べます。**Grok Bot：** 公式ページにはスキルをファイルで取り込む方法が書かれていないので、Botとのチャットに文面を貼り、その名前のスキルとして保存するよう頼みます。保存後、*Connect apps* → *Private skills* で確かめます。 |
| ルーティンの依頼文 | その仕事を持たせるBotに、メッセージとして送ります。*When to run* を読み、安全な入力で *Test* を1回押します。 |
| Botの初期設定の文面 | Botを作り、最初のメッセージとして送ります。長く守らせたい決まりは「覚えておいて」と頼むと記憶に入ります。 |
| 作業手順 | 人が自分で行う確認です。アプリを開いて順に進めます。 |

使う前に `[空欄]` をすべて埋めてください。どの文面も、送信・公開・購入・支払い・削除・本番環境の変更の前で止まります。その行は消さないでください。

## 公式ページに足しているもの

公式ページは機能の説明と、良いスキルやルーティンの依頼に入れるべき点の一覧までです。ここにあるのは、それを書き切った文面です。
スキルは公式が挙げる6要素（使う場面・入力と権限・手順・確かめ方・返す物・承認が要る事）をすべて埋め、ルーティンの依頼文は確かめるべき点をすべて書き込み、
さらに、データが無い・古いときの扱い、途中で終わった実行の報告、2回動いても害が出ない書き方を足しています。文面中の上限は、2026-11-18 時点で公式ページに書かれていたものです。
