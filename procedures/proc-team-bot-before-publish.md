Unofficial checklist: read a Team Bot draft from end to end before anyone else can use it.

1. Write down [TEAM_BOT_NAME] and [AUDIENCE]. A Team Bot stays a Draft until it is published.
2. Open the Bot's details and read About. The description should say the one job in a sentence or two, with no customer names and no internal links.
3. Open Plugins. For each one ask: does the job need it? Remove what it does not need.
4. List the connected apps. Everyone in [AUDIENCE] will act through the same account. Keep only accounts with nothing sensitive behind them.
5. Open Secrets. Everyone who chats with the Bot shares them. Remove any secret that [AUDIENCE] should not be able to use.
6. Open Skills. Read each skill's description and its examples. Remove customer data and private addresses.
7. Open Files. Open every file once. A file you have not opened does not get shared.
8. Read the approval rules that apply to this Bot. Sending, publishing, purchasing, paying, deleting and changing production should be "Ask first".
9. Check the roles: Owner, Manager, Collaborator. Name the Owner or Manager who will look at "Review learnings", because teachings from Collaborators wait there as suggestions.
10. Open each routine and read "Who can use this routine?". Leave it at "Only me" unless the team needs it.
11. Send the draft one harmless request yourself and read what it does with the shared apps.
12. Stop here. The Bot is still a Draft. Publish only when steps 2 to 10 left nothing open.
