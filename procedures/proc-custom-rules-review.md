Unofficial checklist: read your Custom Rules as a set and write down what should change.

1. Write [ASK_FIRST_ACTIONS] and [ALLOWED_ACTIONS] before you open anything. This is your own yardstick.
2. Open Settings, then General, then Bot, then Custom Rules.
3. Copy every "Ask first" rule and every "Allow automatically" rule into a note. Number them.
4. Count them. Each kind holds at most 20 rules, and a rule holds at most 1,000 characters.
5. Read each "Allow automatically" rule and say aloud what it lets through. If you cannot, mark it unclear.
6. Mark for removal any "Allow automatically" rule that reaches sending, publishing, purchasing, paying, deleting or changing production.
7. Compare each line of [ASK_FIRST_ACTIONS] with the "Ask first" rules. Note every action that no rule covers.
8. Compare each line of [ALLOWED_ACTIONS] with the "Allow automatically" rules. Note what is missing, and keep each proposed rule narrow: one app, one folder, one kind of action.
9. Look for pairs where both kinds match the same action. "Ask first" wins there, so the allow rule does nothing; mark it.
10. Look for long rules. Short, narrow rules are easier to predict. Propose a split for any rule that names more than one app.
11. Remember what approval covers: only the proposed action. It does not undo work already done, and a card raised by background work expires after 30 minutes.
12. Stop here with the proposal: rules to remove, rules to add, rules to split. Change them yourself, one at a time, and reread the list after each change.
