Unofficial checklist: find out what a Bot remembers about one topic and put it right.

1. Write down [BOT_NAME] and [TOPIC]. One topic per pass keeps the answer short enough to read.
2. In the chat with [BOT_NAME], ask: "What do you remember about [TOPIC]?" A personal Bot has no memory screen, so asking is the way to see it.
3. Copy the answer into a note. Number the items.
4. Mark each item keep, correct or forget. Do not ask for any change yet.
5. Look for dates, prices, owners and versions. Memory can go stale and is not a source of truth. Check these against a current source. Mark the ones you verified as wrong "correct"; mark anything you cannot verify "unverified" and do not rely on it.
6. Look for logins, card numbers and keys. None should be there. If one is, mark it forget. Logins and card numbers go in Vault; API keys go through a secure secret card.
7. Look for rules. A rule you rely on for safety should also exist as an "Ask first" rule under Custom Rules. Note any that exist only in memory.
8. For each item marked correct, tell the Bot what is out of date and what is true now. One item per message.
9. For each item marked forget, ask it to forget that one item by name. Do not ask it to forget everything.
10. Remember the reach: what a Bot saves in one chat it remembers in all your chats with it, and a few facts about you are shared by all your Bots.
11. Ask the question from step 2 again. Compare the new answer with your marked note.
12. Stop here. Anything still wrong goes on a list for the next pass; do not keep repeating the request in the same sitting.
