Unofficial checklist: carry instructions that used to sit in a personal Bot's Description over to chat.

1. Write down [BOT_NAME] and put your own copy of the old text in [OLD_TEXT]. Work from your copy; a personal Bot has no description and no Bot settings page to read it from.
2. Do not assume the Bot still follows the old text. Ask it: "What do you remember about your job and your rules?" Keep the answer.
3. Mark the sentence in [OLD_TEXT] that states the job. One job per Bot.
4. Mark the lasting rules: what needs approval, what it must never do, which sources it may read.
5. Cross out the rest: greetings, examples you no longer use, anything about a tool the Bot does not have.
6. Remove every login, card number and key. Logins and cards belong in Vault. API keys go through a secure secret card.
7. Send the job as one message in the chat with [BOT_NAME]. Ask the Bot to remember it.
8. Send the lasting rules as a second message, one rule per line. Ask the Bot to remember them.
9. Ask the question from step 2 again. Compare the answer with what you sent, line by line.
10. Correct any line that came back different. Tell the Bot which part is wrong and what is right.
11. For each safety rule, add a matching "Ask first" rule under Custom Rules. Memory alone is not a safety boundary.
12. Team Bot instead? It still has a description, which its owner or a Manager edits under About. Keep that description short and put the working rules in chat as above.
13. Stop here. Give the Bot one harmless request and read the result before you rely on it.
